# Bundled fonts (offline build)

The original Valence Life v3 page loaded these families from fonts.googleapis.com. Y.O.U.R. v2.0 is offline, so local copies are bundled instead:
Atkinson Hyperlegible (Regular, Bold), Barlow Condensed (Medium, Bold), JetBrains Mono (variable), Press Start 2P (Regular), Unbounded (variable).

All five families are published on Google Fonts under the SIL Open Font License 1.1 (https://openfontlicense.org). They may be bundled and redistributed with software; the font files themselves may not be sold on their own. The license text was not in the local font store, so before publishing, add each family's OFL.txt from its Google Fonts / GitHub page.
